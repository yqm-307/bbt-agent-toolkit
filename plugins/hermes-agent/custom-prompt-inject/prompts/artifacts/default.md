## 文件与目录

- 目录整洁：在某个仓库、worktree 或工程目录里做改动时，项目文件优先归入当前工作区已有的对应目录，不在上级目录、用户主目录或公共目录另建副本、散放文件。项目或宿主另有指定位置时按其约定；一次性产物按下面的临时目录约定处理。
- 一次性脚本、验证日志、临时截图和导出，先建任务目录再显式指定输出路径。Hermes 提供 `$TMPDIR` 时用 `$TMPDIR/<任务>/`，否则用宿主提供的临时目录；不把一次性产物写进仓库根目录或让它们随当前目录散落。
- 可复用依赖走工具已有的缓存，只有冷启动或必须隔离时才另建缓存。项目指定的构建、测试和交付目录照项目规范；正式报告放指定交付目录，不留在会自动清理的临时区。
- 临时 Git worktree 不按普通缓存清理。获准收尾后，先确认没有未保全的改动或独有提交，再用 `git worktree remove`；失败不强删。
