# prompt-health 设计边界

## 输入边界

工具接收一个仓库根目录，扫描公开的提示词资产目录。它不读取会话、记忆、环境变量中的凭据或宿主运行时状态，也不假定仓库一定有 skills、agents 或 Git。

## 统一引用检查

skill 引用检查已经并入 `prompt_health.py`，只保留当前仓库即时计算的引用检查：

- `related_skills` 指向不存在的 skill：ERROR；
- skill 名称重复：ERROR；
- 正文提及仓内已知 skill 但未声明：INFO 候选。

不再生成关系图、索引、健康度图指标、影响面缓存或 SVG。引用检查基于当前磁盘/仓库内容即时计算，不维护第二份注册表。

## Gate

`--gate` 只检查可确定的三类问题：引用错误、超过体量上限、重复 Markdown 内容。警告或错误存在时返回 1；工具异常或快照不可读返回 2。普通报告可以包含候选信息，但候选不自动升级成失败。

## 快照

快照只在调用者显式传 `--snapshot` 时写入，并记录 schema、指标和扫描文件摘要。基线属于使用者的仓库状态，不随工具发布；不同仓库、不同扫描范围的快照不能互相比较。
