# C/C++ 公共注释与 Doxygen

## 文档注释

公共声明优先在 `.hpp/.h` 写文档；实现文件不复制同一契约。Doxygen 支持 `/** ... */`、`/*! ... */`、`///` 等文档块；本仓首选 `/** ... */`，便于长说明、Markdown 和标签统一。

```cpp
/**
 * @brief 请求关闭宿主。
 *
 * 幂等地发布关闭意图。若宿主尚未启动，后续 run() 会在启动完成后
 * 进入关闭序列；若已经结束，不改变最终 Closed 状态。
 *
 * @par Thread safety
 * 可从任意线程调用。
 * @note 本函数不等待网络排空。
 */
void request_shutdown() noexcept;
```

默认用内建 `@par Thread safety`。若项目改用自定义 `@thread_safety`，必须在 Doxyfile 配置 `ALIASES`，否则会产生未解释标签。示例只是文档结构，不断言任意 request_shutdown() 都有这些保证，应用到源码前核实真实契约。

## 标签选择

| 事实 | 标签 | 备注 |
|---|---|---|
| 一句话职责 | `@brief` | 必须可脱离实现阅读 |
| 展开说明 | 正文段落 | 空行分段，支持 Markdown |
| 模板参数 | `@tparam` | 写约束和用途 |
| 普通参数 | `@param` | 必要时加 `[in]`、`[out]`、`[in,out]` |
| 返回结果 | `@return` | 写成功/错误语义，不只写类型 |
| 前后置条件 | `@pre` / `@post` | 只写可验证契约 |
| 异常 | `@throws` / `@exception` | 仅在真实异常契约存在时写 |
| 提醒/风险 | `@note` / `@warning` | 不用来堆实现细节 |
| 废弃 | `@deprecated` | 必须给替代入口或迁移说明 |
| 关联接口 | `@see` / `@ref` | 符号真实存在时使用 |

不要为了“看起来完整”给无参数、无返回值、无异常的函数补空标签。不能从函数名推断线程安全、所有权、阻塞性、顺序保证或错误集合；缺事实先读调用方和契约。

## C++ 解析边界

- Doxygen 适合公开类、模板、枚举、函数、成员和继承关系；宏、复杂模板、概念约束和生成代码可能需要预处理配置或人工核对。
- `EXTRACT_ALL = NO` 时只导出有文档或被引用的对象，适合公共 API；不要用 `EXTRACT_ALL = YES` 掩盖缺失注释。
- 公共头的 `#include`、宏和目标标准须与项目真实构建一致；Doxygen 能解析不代表编译器能编译。
- 中文正文可保留，HTML/XML 字符集与字体由文档站点配置；发布前核查中文显示、链接和搜索。

## 运行命令

```bash
# Doxyfile 已由模板变量替换生成；输出目录必须在 build/ 或临时目录。
doxygen build/docs/Doxyfile

# 只检查工具与版本，不代表项目导出成功。
doxygen --version

dot -V
```

真实验收至少检查：退出码、warnings、HTML 中公共符号、参数/返回表、交叉链接、中文显示和图表；需要结构化下游时开启 `GENERATE_XML = YES`。输出目录不入 Git。
