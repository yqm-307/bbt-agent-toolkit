# mwc-sharpen — 任务锐化

把一个任务变深，不是变大。先回答四个问题，再重写 prompt。

## 四个问题

1. 顶级专业人士会做什么你没要求的？
2. 他们会从什么最原始的材料开始，而不是消化过的二手信息？
3. 他们会用什么具体的方法和工具？
4. 除了你或我，还有什么能证明结果是对的？

## 执行

先逐个回答这四个问题，然后基于答案重写原始 prompt。留给用户做的决定保持开放，不替他选。

## 边界

- 只加深，不扩大范围
- 重写后的 prompt 要能直接执行
- 如果原 prompt 已经很锐利，说「已经很清楚了，不需要再锐化」然后停
