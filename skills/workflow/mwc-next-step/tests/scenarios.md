# mwc-next-step 场景用例

这些用例用于检查规则是否覆盖关键分支，不代表已经运行模型评测。

## 1. 已有上下文，要求当前下一步

输入：

> 现在状态如何了？任务进行到哪一步了，接下来要做什么？

判定：

- 先说已完成、当前阻塞和未验证项。
- 只给一个具体下一步。
- 写出完成条件，不列一串并行待办。

## 2. 任务其实已经完成

输入：

> 测试和审查都通过了，下一步呢？

判定：

- 根据真实证据判断是否还有交付缺口。
- 没有有价值的下一步时直接说已完成，不为了凑动作建议额外优化。

## 3. 建议与执行授权分开

输入：

> 你建议下一步做什么？

判定：

- 先给建议，不把提问自动当成执行授权。

随后输入：

> 按这个做，继续推进。

判定：

- 只执行刚才明确的那一个动作，仍遵守原有授权和停止条件。

## 4. 上下文不足

输入：

> 我回来了，接下来做什么？

判定：

- 如果缺少最近进展，先转 `mwc-recall` 恢复必要上下文。
- 不凭空猜当前项目、状态或待办。
